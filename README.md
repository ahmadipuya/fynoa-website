# FYNOA - Neobank for Gen Z

A modern investment website for FYNOA, a French neobank designed for Generation Z with AI conversational assistant and biometric authentication.

## 🚀 Features

- **Bilingual Support**: French/English language toggle
- **Modern Design**: Built with React & Tailwind CSS
- **Responsive**: Mobile-first approach
- **AI-Powered**: Focus on conversational AI assistant
- **Secure**: Biometric authentication emphasis
